# suechen.me

Public site for **suechen.me** (GitHub Pages, apex domain).

`index.html` is a generated, self-contained page — do not hand-edit.
Source + build pipeline live in the private staging repo `suechen-homepage`
(`build.py` + `content.md` + `template.html` → `site.html` → copied here as
`index.html`). To update: edit in staging, rebuild, copy `site.html` here, push.

`CNAME` binds the apex domain; `.nojekyll` disables Jekyll processing.
